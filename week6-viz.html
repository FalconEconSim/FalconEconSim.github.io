Fig 6.1 Cost Minimisation Sandbox

Set the wage w, capital rental rate v, and target output q. The isoquant and isocost family appear. Drag the bundle and watch MRTS vs w/v update in real time. The bundle turns green when you hit the tangency condition MRTS = w/v.

Wage w: 4
Rental rate v: 4
Output q: 3
Fig 6.2 Two-Panel Cost Derivation

Left panel: isoquant map with the expanding isocost sweeping across output levels. Right panel: TC(q) curve building itself point by point. Step through output levels to watch each cost-minimising bundle map to a TC value.

Isoquant map + isocost
Total Cost curve TC(q)
Fig 6.4 Bang-for-the-Buck Reallocation Engine

Set MPL, MPK, w, v. The two bars show MPL/w vs MPK/v. An animated dollar flows from the overpaid input to the underpaid one, and the bars converge to the optimum. This directly addresses the most common exam error: students forget to equalise the marginal products per dollar.

MPL: 12
MPK: 8
Wage w: 4
Rental v: 4
Fig 6.5 SR vs LR Cost Curves

SMC, AVC, ATC, and AFC drawn simultaneously. A TFC slider shows how fixed costs shift ATC but not SMC or AVC. A toggle overlays the LRAC for comparison. All five short-run curve properties in one diagram.

TFC: 100
Fig 6.6 LRAC Envelope Builder

Add SRAC curves (each corresponding to a different plant size K). The LRAC envelope redraws after each addition, always hugging from below. The tangency point for each SRAC is highlighted. Watch the "lower envelope" concept build itself live.

Fig 6.8 Minimum Wage Automation Simulator

A firm is at cost-minimising (L*, K*) on an isoquant. Raise the minimum wage w. The isocost rotates, the old optimum turns red ("no longer optimal"), and the new tangency animates to a more capital-intensive point. Watch K/L and TC update live.

Min wage w: 3
Capital cost v: 3
Fig 6.10 Efficient Scale Finder

Enter any AC function (pre-loaded with AC = 100/q + q). The tool plots AC, marks q* where dAC/dq = 0 (the efficient scale), shades economies of scale in green and diseconomies in red. A second panel shows the implied industry structure.

AC function (type a, b for AC = a/q + b*q):
AC = /q + q
