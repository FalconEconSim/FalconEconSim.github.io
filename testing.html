Testing: Label Collision Experiments

This page is a developer sandbox for exploring label collision avoidance in economic diagrams. Economic visualizations frequently have multiple labels (prices, quantities, equilibrium points) that overlap when plotted naively. Three distinct approaches are compared here with live, interactive demos. This page is not linked from the main course navigation.

← Course Home 📊 Week 7
Approach 1 Labella.js - Force-directed label placement for 1D spaces

Labella.js solves the 1D label placement problem: given a set of labels that must stay on one axis (e.g. a price axis), it shifts labels along that axis to remove overlaps while minimizing the total displacement. It uses a force-directed algorithm optimised specifically for timelines and axis annotations, drawing connector lines back to the true data positions. The demo below shows 8 equilibrium price/quantity labels on a supply-demand diagram. Toggle between the raw (colliding) layout and the labella-resolved layout.

+ Best for 1D axis labels + Minimal displacement objective + Tiny file size (~12 kB) - Only works along one axis - No 2D scatter label support Use case: timeline events, axis tick labels

Approach 2 D3 Force Simulation - Physics-based collision avoidance

D3's force simulation applies physics-like forces to SVG elements. By combining d3.forceCollide (labels repel each other) with d3.forceX / d3.forceY (labels are attracted back toward their data points), you get 2D label placement that works in any direction. Labels in the demo below are also draggable. Connector lines update in real time.

+ Works in 2D - any direction + Fully interactive (drag, animate) + Highly customisable forces - Larger dependency (D3 ~280 kB) - Convergence not guaranteed Use case: scatter plots, 2D diagrams

Approach 3 AG Charts - Built-in collision avoidance for chart libraries

AG Charts (Community edition) is a full charting library with built-in label collision avoidance. When multiple series data points crowd together, AG Charts automatically hides, repositions, or offsets labels to prevent overlap, with no custom code required. The demo below recreates a revenue-rectangle-style diagram (inspired by Fig 4.3 from Week 4) showing total revenue, consumer surplus, and producer surplus regions annotated with automatic labels.

+ Zero collision code needed + Production-quality chart output + Tooltips, themes, legends built in - Large bundle (~450 kB) - Less control over label positions Use case: standard chart types with dense labels
