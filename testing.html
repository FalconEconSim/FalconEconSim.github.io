Section 3Force Label Approaches

4 different collision-avoidance algorithms. All use 12 px font on a 460 px canvas. Drag the slider to move the MR = P price line and watch all four panels re-resolve their labels at once.

$9 drag → all 4 panels update
A, Current: spring-back + mild push
150 iter, push 0.5×, spring pulls label 5% back to anchor each iter, line-repel 0.4×. Labels stay close to anchor but may still overlap lines.
B: Strong push, no spring, pre-offset
Labels pre-positioned 30 px away from nearest line before iteration. 250 iter, push 0.8×, no spring, line-repel 0.7×. Labels float freely; connector shows anchor.
C: Smart pre-placement (away from curves)
Each label pre-placed 38 px in the direction away from the average of its 20 nearest line points. Then 90 iter light resolve. Labels start on the right side from the beginning.
D: Best-of-8 compass positions
For each label, tests 8 compass directions (R = 42 px). Picks the position with fewest overlapping labels + line points. Then 70 iter fine-tune. Structured, predictable placement.

Below: velocity-based approaches, labels have inertia (D3-style). Forces shrink via alpha decay so labels settle gradually instead of jumping.

E: Alpha-decay velocity + elliptical collision
Labels gain velocity each step; forces scale with alpha (1→0 over iters). Elliptical collision replaces rectangular bounding-box check. Weak spring to anchor. Closest to D3 feel.
F: Pre-offset + physics, no spring
Labels start 32 px from nearest line point, then velocity physics with NO spring. They float to the clearest region and stay. Strongest line avoidance of all 8.
G: Best-of-8 start + physics settle (D + E hybrid)
Compass placement picks a clean starting point (approach D), then alpha-decay physics smooths the result. Combines structured placement with organic settling.
H: Smart pre-place + physics, loose damping
Smart directional pre-placement (away from curves), then physics with high damping = 0.88 instead of 0.76. Velocity persists longer, giving a more “floaty” feel and wider label spread.

Section 7 D3 Force Simulation: Physics-based collision avoidance

D3's force simulation applies physics-like forces to SVG elements. By combining d3.forceCollide (labels repel each other) with d3.forceX / d3.forceY (labels are attracted back toward their data points), you get 2D label placement that works in any direction. Labels in the demo below are also draggable. Connector lines update in real time.

+ Works in 2D, any direction + Fully interactive (drag, animate) + Highly customisable forces - Larger dependency (D3 ~280 kB) - Convergence not guaranteed Use case: scatter plots, 2D diagrams
